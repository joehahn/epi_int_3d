inclined: inclined test particles (epi_int_3d)¶

tests/unperturbed's 51 eccentric streamlines (3 particles each, 10⁻⁸ < e < 10⁻²), without ring forces, each particle given inclination i = 0.01, run for 1000 orbits with fast/epi_int_3d.py. Expectations (notes/equations.md V1–V4, V8):

  1. every particle keeps its inclination;
  2. its node regresses at Ω_a − ν_a, about 270 orbits per cycle here;
  3. integrated exactly in the 3D J2 potential, the same particles regress at a rate within O(i², e²) of that.

Make the output with uv run python tools/run_simulations.py tests/inclined (about 2 s).

3: versus exact integration in the 3D J2 potential¶

Particle 0 of every streamline, integrated with DOP853 from its state at the first output; its node is measured with the same epicyclic elements (V3) as the code's, which removes most short-period terms.

The code's nodes regress faster than the exact ones by 4i², the first-order theory's O(i²) error. Its origin is simple: the code's semimajor axis comes from h_z = r v_θ = h cos i, so a_code = a cos²i, and the nodal rate ∝ a^(−7/2) cos i, so exact/code = cos⁸i ≈ 1 − 4i². Runs at i = 0.003 and 0.001 give the same −4.04 i², with scatter 2×10⁻⁶ and 6×10⁻⁷ for e < 10⁻⁴.

For e ≳ 10⁻³ the difference grows roughly as e² (coefficient −3 to −4), with a few outliers. Those come from the measurement: the exact orbits' nodes (V3) carry short-period terms of amplitude ≈ 2e rad (the theory's O(e·i) error in z, V6), which the 10-orbit spacing of the outputs aliases into slow wobbles that bias the fitted rates.
