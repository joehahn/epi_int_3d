epi_int_3d animations

Animations of simulations made with epi_int_3d, a streamline N-body code for planetary rings, with play, pause and a frame slider.

A spiral bending wave

A satellite's m = 2 vertical resonance launches a spiral bending wave in a self-gravitating ring; the test and its comparison with linear theory are in bending_waves.ipynb.

  • The ring's height, face-on: grayscale, white above the plane and black below, in the frame rotating with the pattern; the ring's width is stretched radially.
  • The ring's height, streamline by streamline: every 9th streamline's height versus longitude, each offset by its distance from resonance.
