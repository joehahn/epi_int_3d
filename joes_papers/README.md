# joes_papers

The author's (J. M. Hahn's) own papers, kept apart from the reference papers by others in `/papers/`.
They are the source of `writing_style.md`, the author's style for the paper (`/paper/epi_int_3d.tex`),
and some are also cited references.

How the style guide is managed, and why: the paper should read as the author's own writing, so the AI
drafts its text from `writing_style.md` rather than from its own habits. The guide is drawn from these
papers, favoring the recent ones where the author's habits have changed, and records each choice the
author makes while editing the paper, with its date. The AI proposes changes to it, and the author
approves them. Keeping the author's papers here, apart from the reference papers by others, keeps the
guide's sources clear: only the author's own writing defines the style.

Only papers with an open license are committed to this repo; for the others, use the DOI or arXiv links below and keep a local copy here, which git ignores
(see `/.gitignore`).
